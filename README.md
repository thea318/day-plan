# Healthy Day Plan

A quick browser project for tracking a simple daily meal plan, daily habits, one planned sweet, and a two-week dairy break.

## What It Includes

- Breakfast, lunch, snack, and dinner option pickers.
- Daily habit checkboxes for water, sunlight, meals, and sleep.
- One planned sweet per day.
- A streak counter for days when everything is completed.
- A two-week reminder to avoid milk, ice cream, milkshakes, and large amounts of cheese.
- Browser storage so today's selections stay checked.

## Open Locally

You can open `index.html` directly in a browser.

For installable PWA behavior, run a local server from this folder:

```sh
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/index.html
```
