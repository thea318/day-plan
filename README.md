# Habit Rewards

A pink summer habit tracker with reward jobs, parent approval, streak rewards, and confetti.

## Open Locally

Run a local server from this folder:

```sh
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/index.html
```

## Install On Phone

After deploying to GitHub Pages, open the GitHub Pages link on your phone.

- iPhone: tap Share, then Add to Home Screen.
- Android: tap the browser menu, then Add to Home screen or Install app.
